# Research

Investigates decision-relevant questions from primary sources and writes one cited, auditable HTML dossier with an explicit as-of boundary. Three rules: primary sources own the claims; one dossier, every claim cited; the claim audit — an unsupported assertion is repaired or its gap named, never softened into cautious-sounding prose.

The dossier lands on an artifact branch (`artifact/<ticket>-<slug>`, or `artifact/<slug>` when ticketless) and its render link goes to the record that raised the question — the ticket, or the raising conversation. Independent subquestions may fan out through `to-subagent`.

Install with `npx skills add <repo-url> --skill research`.
