# Prototype probes

Pre-deployment probes with only `SKILL.md` in context. Require an exact citation for each answer.

## Scenario

You are prototyping whether a payout flow should be a wizard or a single form.

## Probes

**P1.** The request was "prototype the payout stuff." What happens before building?

**P2.** The variants differ only in color. Is that enough?

**P3.** The variants are built. What must happen before iteration?

**P4.** Choosing a variant needs human judgment. What do you return?

**P5.** The chosen prototype code looks clean. Does implementation ship it?

## Answer key

- **P1:** State one question and what settles it before building.
- **P2:** No. "Vary layout, hierarchy, or primary affordance, not only color or copy."
- **P3:** "Make the artifact launchable, show its relevant state, and open or drive it directly."
- **P4:** Return "the artifact path, what it demonstrates, and any choice that still needs human judgment."
- **P5:** No. "Implementation rebuilds the chosen experience or lifts the validated logic; the prototype itself never ships."

Pass bar: five of five on both executors.
