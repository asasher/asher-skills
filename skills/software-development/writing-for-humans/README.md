# Writing for humans

Reference skill: the communication standard for conversation; the standard lives in SKILL.md.

## Provenance

The presentation guidance is an original rewrite inspired by HumanLayer's [`show-me`](https://github.com/humanlayer/skills/blob/bba9d13ab34f0a87f1cc33df4dd196372393ddfc/plugins/show-me/skills/show-me/SKILL.md), reviewed at commit [`bba9d13ab34f0a87f1cc33df4dd196372393ddfc`](https://github.com/humanlayer/skills/commit/bba9d13ab34f0a87f1cc33df4dd196372393ddfc). It adopts the idea of matching the visual form to the information, scoped to conversation. No external skill installation is required.

The voice guidance adapts the "adding soul" section of Cursor pstack's MIT-licensed [`unslop`](https://github.com/cursor/plugins/blob/bdf7aa355337897f167153e05069aca505dae17c/pstack/skills/unslop/SKILL.md), reviewed at commit [`bdf7aa355337897f167153e05069aca505dae17c`](https://github.com/cursor/plugins/commit/bdf7aa355337897f167153e05069aca505dae17c). License in [THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md).

The rhythm demonstration quotes Gary Provost's "write music" passage from "100 Ways to Improve Your Writing" (1985) as fair use for teaching, with one edit: the em dash is a comma, to match the family's punctuation standard.
