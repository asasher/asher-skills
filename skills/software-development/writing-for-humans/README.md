# Writing for humans

Reference skill holding the communication standard for user-facing text: ASD-STE100 writing-for-humans discipline, the project's glossary (conventionally `CONTEXT.md`) as the approved technical dictionary, and the no-opaque-numbers rule for ticket and PR references. Every user-facing skill cites it by name so the standard has a single source of truth; it defines the standard, and citing skills apply it in place.

## Provenance

The writing-for-humans discipline follows ASD-STE100 Simplified Technical English (ASD, the AeroSpace and Defence Industries Association of Europe). No text is reproduced from the specification.
