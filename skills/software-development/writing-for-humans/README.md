# Writing for humans

Reference skill: the communication standard for user-facing text; the standard lives in SKILL.md.

## Provenance

The writing standard follows ASD-STE100 Simplified Technical English (ASD, the AeroSpace and Defence Industries Association of Europe). No text is reproduced from the specification.

The human-voice editing pass adapts Cursor pstack's MIT-licensed [`unslop`](https://github.com/cursor/plugins/blob/bdf7aa355337897f167153e05069aca505dae17c/pstack/skills/unslop/SKILL.md), reviewed at commit [`bdf7aa355337897f167153e05069aca505dae17c`](https://github.com/cursor/plugins/commit/bdf7aa355337897f167153e05069aca505dae17c).
