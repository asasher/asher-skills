# Shape

Settles one subject's strategic decisions — an idea or a ticket — in an interactive thread, ending in a spec blessed at a commit hash. Stateful: the record lives in the ticket thread and on the subject's artifact branch, and a resumed session re-asks nothing the record answers. `SKILL.md` is the single source for the mechanics — the loop, crystallisation, the comment watch, and the blessing.

## When to use

- Work needs its strategic decisions settled before anything builds on it.

## Dependency surface

Sibling composition and degradations are declared in `SKILL.md`.
