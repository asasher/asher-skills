# Shape

Shapes one ticket into a published spec. The ticket's work branch carries project context changes into the later build and its single change request. Research and prototype questions run in fresh subagents; `shape` publishes their artifacts and the final spec to artifact branches, deploys durable renders, and projects each revision onto the ticket. Implementation design uses the `principle-codebase-design` and `principle-type-system-discipline` siblings, with `typescript-best-practices` for TypeScript targets when available.
