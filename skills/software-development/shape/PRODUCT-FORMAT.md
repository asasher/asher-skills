# PRODUCT.md Format

## Structure

```md
# {Product Name}

## User types

{The roster. One entry per type — user, admin, API / MCP consumer every type the product serves. Per type: who they are, their situation, the job to be done. Shaping selects affected types from this list; a change that invents a new type extends it.}

```

## Rules

This skill doesn't fully own `PRODUCT.md` so only write to `## User types` section unless otherwise instructed.
