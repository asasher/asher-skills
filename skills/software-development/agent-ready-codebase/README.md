# Agent-ready codebase

Reference skill holding the repo-readiness standard for parallel agent builds: the four-item checklist (worktrees, stack per worktree, auth per worktree, maintained seed), the certify-and-punch-list method, and the use-vs-change rule for genuinely shared resources. It defines the standard; whatever workflow certifies the repo cites it by name and writes the repo's answers into `docs/agents/environment.md`; punch-list gaps become tickets in the tracker.
