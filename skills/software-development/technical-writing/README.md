# Technical writing

Reference skill: the writing standard for durable artifacts; the standard lives in SKILL.md.

## Provenance

The standard distills rules from ASD-STE100 Simplified Technical English (ASD, the AeroSpace and Defence Industries Association of Europe) and the Google developer documentation style guide. No text is reproduced from either.

The layering and the tired-reader bar adapt Cursor pstack's MIT-licensed [`technical-writing`](https://github.com/cursor/plugins/blob/b047069f4f3a73e87dd1f11f7913386d25876b91/pstack/skills/technical-writing/SKILL.md), reviewed at commit [`b047069f4f3a73e87dd1f11f7913386d25876b91`](https://github.com/cursor/plugins/commit/b047069f4f3a73e87dd1f11f7913386d25876b91).
