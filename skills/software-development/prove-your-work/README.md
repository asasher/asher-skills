# Prove Your Work

Evidence packaging for a finished change, posted as a comment on the PR where the merge decision happens. Evidence media uploads through `to-web` and embeds by URL instead of entering the repo; SKILL.md holds the package contents, the media format, the mechanical embed check, and the bar each part must meet.

## When to use

- A PR has converged and the decider will not have watched the work.

## Dependency surface

Composes with the optional `to-web` and `technical-writing` siblings; reads `docs/agents/environment.md` when the repo has one.

## Provenance

No external sources.
