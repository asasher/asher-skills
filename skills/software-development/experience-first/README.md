# experience-first

Reference skill holding the decision-ordering standard for shaping: users → experience → system behavior → implementation. Experience decisions sit above implementation decisions in the tree; the seam between them is a named handoff point; implementation is recommended rather than asked when one good design exists; registers with empty frontiers are skipped; blessing is per register against the spec's commit hash. Cited by the shaping-layer skills; it defines the standard, and citing skills apply it in place.
