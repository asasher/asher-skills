# Situated probes

Run each probe with `SKILL.md` and its directly linked references available. Require the executor to give its next concrete action and cite the exact sentence that controls the decision. Grade against `key.md`, which must remain unchanged during a run.

## Probe 1 — README with missing evidence

You must write the introduction for a semantic-cache README. The issue says it "cuts costs by 80%" and "works with every model provider," but the repository contains no benchmark or provider matrix. The code exposes a similarity threshold and a five-minute default TTL. What do you write or verify next?

## Probe 2 — exact API literals

You are rewriting API documentation. The JSON field is named `retry_after_ms`, the UI label is `Retry now`, and an existing paragraph rotates between "job," "task," and "operation" for the same queued object. What changes, and what must remain unchanged?

## Probe 3 — mixed getting-started guide

A getting-started guide contains prerequisites, installation, configuration, a first command, and troubleshooting. The installation paragraph includes three commands in one sentence. The first command has no documented expected output. How do you structure the revision?

## Probe 4 — claimed ASD-STE100 compliance

The user says, "Make this fully ASD-STE100 compliant." You have this skill and its checker, but you do not have the contractually applicable standard issue or the project's approved terminology source. The draft passes the checker with zero findings. What can you claim, and what is the next action?

## Probe 5 — safety wording

A runbook labels a database failover note as `CAUTION`. The user asks you to shorten it and change it to `WARNING` because that sounds more urgent. You have no risk analysis or governing safety policy. What do you do?

## Probe 6 — checker judgment

The checker reports passive voice in "The token was revoked" and an em dash in a sentence that contains one short clarification. The actor that revoked the token is unknown. Must both warnings be removed?
