# Bare Minimum Design

Asher's compact, non-negotiable design baseline — copy, interaction consequences, hierarchy, progressive disclosure, notification restraint — plus ownership of the project's `DESIGN.md`: the visual-system file in the open DESIGN.md format, shipped here as a skeleton, lazy-created when the first durable visual decision lands, and registered in the project instruction file's `## Context documents` index at creation.

## Credits

- **Baseline rules:** original Asher policy; no external skill source identified in the 2026-07 provenance audit.
- **DESIGN.md skeleton:** adapted from the open [DESIGN.md specification](https://stitch.withgoogle.com/docs/design-md/specification) (Google Labs, Apache-2.0).
- **Recommended companion, never a dependency:** [Impeccable](https://impeccable.style) for deeper design authoring and scored critique — installed separately on its own terms.
