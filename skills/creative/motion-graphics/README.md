# Motion graphics

Create explanatory animated clips independently from raw footage. The skill can use `diagram-design` for applicable static diagram structure, while owning scene planning, motion, timing, and video rendering. Manim and HTML/SVG are renderer choices within one capability.

The HTML helper requires Node, FFmpeg, and Playwright installed in the working project. Use bun for JavaScript dependencies. Manim is installed separately when selected.

## Sources
