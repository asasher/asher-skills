# Portrait delivery

Choose the platform, placement, locale, and extra interface elements before laying out a Short. Treat playback overlays separately from cover/profile-grid crops. Use a dated, project-owned profile: canvas, exclusion rectangles, caption lane, evidence source, and app-verification status.

The bundled `references/safe-zone-profiles.json` contains measured official ad-template references dated September 18, 2026. Copy a selected profile into the project when useful and check the current destination guidance. These references are not verified organic playback specifications. Their coordinates use a 1080 × 1920 canvas; scale with the output and round exclusions outward.

- YouTube Shorts has organic editor visual guides showing potential overlap with buttons, descriptions, and device edges. Prefer those guides for the delivery check. The bundled Google rectangle comes from its broader vertical-ad template.
- Meta's 9:16 ad diagram includes top, bottom, and side exclusions plus a lower-right inset. For Reels ads with disclaimers, reserve the full bottom 40%. Check cropping on taller screens.
- TikTok's standard LTR ad profile differs from anchor and Arabic-region RTL variants. Choose the corresponding official template when those apply. Description length and additional formats can change usable space; the live placement can differ from preview.

Keep labels, meaningful actions, faces, and complete caption plates clear of exclusions. Backgrounds can bleed to the frame edges. Pass the profile and caption lane as geometry inputs when constructing animated scenes. Check moving objects throughout their paths.

For a shared export, use the union of destination exclusions. The bundled intersection rectangle is a conservative starting region, not a mandated composition. If it crowds the explanation, render separate destination layouts from the same editorial timeline. Split dense diagrams into beats before reducing type size.

Render a review version with guide overlays and inspect it at phone size. Check the longest caption, scene transitions, and the lowest/rightmost meaningful elements. Keep guides out of the delivered file. Then check the destination's draft/editor preview with actual post copy, captions, and extra overlays. Record the device, date, and result; mark app verification pending when access is unavailable. Check covers and feed crops separately. Previewing does not require publishing the post.
