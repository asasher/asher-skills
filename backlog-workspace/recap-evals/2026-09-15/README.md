## Review the report

Read the main view for 30–60 seconds. Can you explain what shipped and why it matters? Are the numbers and visuals useful? Open the supporting details only afterward. Note anything confusing, verbose, missing, or misleading, with the relevant passage or figure.

Record human feedback separately in that version's `feedback.md`, identifying Asher's feedback and acceptance decision. Keep agent observations in a separate file.

## Compare later versions

Preserve each delivered report unchanged. A revised report or a fresh run goes into the next version directory, with its own prompt and revision record. State whether it was regenerated by the skill or edited directly.
