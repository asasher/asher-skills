Org chart + trees · Diagram Design

The backlog family, restructured

Three figures. The first shows the orchestration scale: backlog is thin, each verb fans one run of a skill that works on exactly one unit and can be invoked on its own. The next two expand the two verb skills that compose the most, shape and deliver. Names in boxes are installed skill names.

Cross-cutting · dispatch and isolation

Adapters every verb reaches by name

  • to-thread spawns an attended session in the outermost harness. groom and build fan one per unit.
  • to-subagent is the only route to unattended work: one blocking call, one brief, deliverable checked on return. staffing picks its model.
  • worktree gives each unit its own working copy. The dispatcher prepares it, merge removes it.
  • handoff stays a standalone user tool: compact this session for the next one.

Cross-cutting · reference skills

Cited by name, never run

  • Writing: unslop, writing-for-humans, technical-writing.
  • Readiness: agent-ready-codebase, the standard backlog setup certifies against and build gates on.
  • Principles: principle-experience-first, principle-codebase-design, principle-type-system-discipline, with typescript-best-practices for TypeScript.

What moves

Renames, folds, and exits

  • to-backlog → capture; build-change → deliver (provisional); merge-change → merge.
  • watch-until folds into merge. retro joins the family.
  • Out of the install: skill-loop (authoring tooling), to-tailnet (personal).
  • One playbook: docs/agents/environment.md. Platform fixed: GitHub, git, a bucket. Labels fixed: six readiness roles, three work-types.
