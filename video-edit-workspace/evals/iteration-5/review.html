Read the caption transcript

A lot of time, there's temptation to just get an agent, connect it to all of your tools, and just set up some schedules and let it run. Which is a recipe for disaster. You implement a very nice email answering workflow or email follow-up workflow. But the agent that you use has access to your private data, and it has access to reply to the email. That is where the trouble starts because these models cannot yet differentiate content from instructions. The agent that reads the email only returns whether or not it requires a follow-up and what that follow-up is. That's it. After that, deterministic code picks up. That code takes that email and writes a draft for a human to approve. But the important thing is, the agent that is exposed to untrusted content is not the same agent that has access to sensitive information or has access to communicate externally.
