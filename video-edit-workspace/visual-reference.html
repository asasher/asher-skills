My recommendation

Use DeepFilterNet 3 for the denoising pass. It has a native Apple Silicon executable and processed this excerpt locally. No cloud service or model training was needed.

Keep FFmpeg for extracting the microphone track, preserving timing, setting final loudness, and combining audio with the video. The neural model handles noise suppression.

RNNoise is the lighter alternative if we later want suppression during recording. It is another local neural model; I haven't compared it on this excerpt.

This test establishes that the local pipeline runs. Your listening verdict decides whether it sounds better.

Mic track → DeepFilterNet 3 → loudness pass → final video
Test details and sources

DeepFilterNet executable v0.5.6 with explicit DeepFilterNet3 ONNX weights. Gentle: 12 dB attenuation limit. Stronger: 24 dB. Post-filter disabled. 48 kHz mono WAV; 14.000 seconds each. These limits control the permitted suppression, not a measured improvement.

Source: September 14 Recap take 1, 00:16–00:30, fourth Program audio track. Playback versions use linear gain matched over identical transcript speech windows, followed by a common peak-safe gain. No EQ or compression was added to the comparison. Model delay is compensated; all final files retain the source duration.

Inference ran locally. These review copies are hosted with this page for playback. Human quality review is still pending.
